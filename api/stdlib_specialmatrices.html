stdlib_specialmatrices (module)#

Provides derived-types and associated specialized linear algebra drivers for highly-structured matrices commonly encountered in the discretization of partial differential equations, as well as control and signal processing applications. (Specification: stdlib_specialmatrices)

tridiagonal (interface)#

tridiagonal (interface)

(Specification: stdlib_specialmatrices) This interface provides different methods to construct a tridiagonal matrix. Only the non-zero elements of \(A\) are stored, i.e.

\[\begin{split}A = \begin{bmatrix} a_1 & b_1 \\ c_1 & a_2 & b_2 \\ & \ddots & \ddots & \ddots \\ & & c_{n-2} & a_{n-1} & b_{n-1} \\ & & & c_{n-1} & a_n \end{bmatrix}.\end{split}\]

real(dp), allocatable :: dl(:), dv(:), du(:)
type(tridiagonal_rdp_type) :: A

dl = [(i, i=1, n-1)]
dv = [(2*i, i=1, n)]
du = [(3*i, i=1, n)]
A = Tridiagonal(dl, dv, du)

  • Construct a real tridiagonal matrix with constant diagonals:

integer, parameter :: n
real(dp), parameter :: a = 1.0_dp, b = 1.0_dp, c = 2.0_dp
type(tridiagonal_rdp_type) :: A

A = Tridiagonal(a, b, c, n)

spmv (interface)#

spmv (interface)

(Specifications: stdlib_specialmatrices) This interface provides methods to compute the matrix-vector product

$$ y = alpha mathrm{op}(A) x + beta y$$

for the different matrix types defined by stdlib_specialmatrices.
