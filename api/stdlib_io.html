stdlib_io (module)#

Provides a support for file handling (Specification: stdlib_io)

version: experimental

Reads a whole ASCII file and loads its contents into a string variable. (Specification: stdlib_io)

Summary

Subroutine interface for reading the content of a file into a string.

Description

This subroutine reads the entirety of a specified ASCII file and returns it as a string. The optional err argument allows for handling errors through the library’s state_type class. An optional logical flag can be passed to delete the file after reading.

Notes

Handles errors using the library’s state_type error-handling class. If not provided, exceptions will trigger an error stop.

open (function)#

function open(filename, mode, iostat) -> u

Opens a file (Specification: stdlib_io)

Arguments:
filenamecharacter(len=*), intent(in)
modecharacter(len=*), intent(in), optional
iostatinteger, intent(out), optional
Returns:
uinteger

Behavior

To open a file to read:

u = open("somefile.txt")        ! The default `mode` is "rt"
u = open("somefile.txt", "r")

To open a file to write:

u = open("somefile.txt", "w")

To append to the end of the file if it exists:

u = open("somefile.txt", "a")

loadtxt_rsp (subroutine)#

subroutine loadtxt_rsp(filename, d, skiprows, max_rows, fmt, delimiter)

Loads a 2D array from a text file.

Arguments#

Filename to load the array from

Arguments:
filenamecharacter(len=*), intent(in)

The array ‘d’ will be automatically allocated with the correct dimensions

dreal(kind=sp), allocatable, (:, :), intent(out), dimension(:,:)

Skip the first skiprows lines. If skipping more rows than present, a 0-sized array will be returned. The default is 0.

skiprowsinteger, intent(in), optional

Read max_rows lines of content after skiprows lines. A negative value results in reading all lines. A value of zero results in no lines to be read. The default value is -1.

max_rowsinteger, intent(in), optional
fmtcharacter(len=*), intent(in), optional
delimitercharacter(len=1), intent(in), optional

subroutine get_file_string(filename, file, err, delete)

Reads a whole ASCII file and loads its contents into a string variable. The function handles error states and optionally deletes the file after reading.

Arguments:

Input file name

filetype(string_type), intent(out)

Output string variable

errtype(state_type), intent(out), optional

[optional] State return flag. On error, if not requested, the code will stop.

deletelogical, intent(in), optional

[optional] Delete file after reading? Default: do not delete
