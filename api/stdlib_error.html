check (subroutine)#

subroutine check(condition, msg, code, warn)

Checks the value of a logical condition (Specification: stdlib_error)

Arguments:
conditionlogical, intent(in)
msgcharacter(len=*), intent(in), optional
codeinteger, intent(in), optional
warnlogical, intent(in), optional

Behavior

If condition == .false. and:

  • No other arguments are provided, it stops the program with the default message and exit code 1;

  • msg is provided, it prints the value of msg;

  • code is provided, it stops the program with the given exit code;

  • warn is provided and .true., it doesn’t stop the program and prints the message.

Examples

If a /= 5, the following stops the program with exit code 1 and prints Check failed.:

call check(a == 5)

To print a == 5 failed., use:

call check(a == 5, msg='a == 5 failed.')

To emit the message without stopping the program, use:

call check(a == 5, msg='a == 5 failed.', warn=.true.)

To stop the program with exit code 77, use:

call check(a == 5, msg='a == 5 failed.', code=77)
